# Words, sentences, and paragraphs

This note is for someone who already has a Business database. The foreign key in `schema.xml` is the constraint. A column that references `Word`, `Sentence`, or `Paragraph` stores that table's id. Views join that table. A Word id in a Sentence column is a different table, so `I18NSentence` does not return it.

`Word.value` is `varchar(25)`. Another culture is another row on the same id. `I18NWord`, `I18NSentence`, and `I18NParagraph` are how a reader sees the row for `ClientCulture()`, which defaults to 1033 (en-US).

For new copy that is not already a linked column, text shorter than a sentence is a fit for Word, text shorter than a paragraph is a fit for Sentence, and longer text is a fit for Paragraph. A page or a mail can be separate Word, Sentence, and Paragraph rows, ordered as content elements, so each piece can be translated and the page is the combination. That is a note about new copy. It does not replace a foreign key.

## A page or a mail

One content id stays put. Editions change. Each element is one Word, or one Sentence, or one Paragraph, in `sequence` order. `Sample/SQL/Content/thank-you.sql` is a sentence followed by a word on one content id. Another culture is another row on those same ids. Dynamic elements and squash are in `docs/0.2.15-downstream.md`.

## Which id a column stores

Sentence: `Site.name`, `Format.name`, `Content.name`, `Campaign.name`, `Part.name`, `VertexName.name`, `Location.marquee`, `Process.name`, `Step.name`, `Variance.name`, `PeriodName.name`, `LedgerName.name`, `JournalName.name`, `BookName.name`, `AccountName.name`, `JobName.name`, `ScheduleName.name`, `AgentString.userAgentString`.

Paragraph: `PartDescription.description`, `Step.description`, `Variance.description`.

Word: `Application.name`, list name, list set, `SessionToken.type`, `FormatAttribute` name, value, and target.

`IndividualSessions` reads `Site.name` through `I18NSentence`. `GetSite(varchar)` calls `GetSentence` and stores that id. A site that already holds a Word id for the same text is returned as that site. See `docs/0.2.15-downstream.md`. `GetApplication` stays on `GetWord` because `Application.name` links to Word.
