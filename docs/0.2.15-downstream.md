# Sites named before 0.2.14, and the SQLite shop

`GetSite(name)` stores a Sentence id on a new site. A site created earlier can still hold a Word id in `Site.name`. `GetSite` returns that site when the word text is the same name. It does not change `Site.name`, and it does not insert a second site. Session rows stay on the original site id.

`IndividualSessions.siteName` reads `Site.name` through `I18NSentence`. A Word id does not come back from that join, so the name is blank until the column holds a sentence id.

On SQLite, `EntitlementCurrent` compares `ends` to `CURRENT_TIMESTAMP`. PostgreSQL still uses `ClientNow()`.

`JournalReport` and `LedgerReport` print two decimal places. The total is the sum of those cent amounts. `JournalEntry.amount` stays four decimal places. `Book` and `Post` write a new amount as four decimal places. They do not rewrite a row already stored.

`AccountLedger` lists every unposted line for the account, on every journal. A `Book` line and a `Post` line both appear.

`ContentElement.name` and `ContentElement.type` are identifier ids. Each points at one `Word` row whose `culture` is null, the row `GetIdentifier` stores. They are set together, and only on an element whose word, sentence, and paragraph are all null. `SetContentElement` calls `GetIdentifier` for those two strings when it writes that element. It does not call `GetIdentifier` while reading.

`ContentElement.squash` is the same kind of id, and it may be null. Null means the element renders alone. A non-null id names a squash type. The 10-argument `SetContentElement` calls `GetIdentifier` for that string on the write. A null or empty string stores null. The shorter forms pass null. `ContentElements`, `ContentHistory`, `ContentBody`, `SiteContent`, and `ListContent` return that culture-null word. Null stays null. The default HTML, MIME, and text renderers join a consecutive run that shares a class and has squash set. The texts join with one space. Any squash word is a space for now. A custom renderer receives the pieces still separate, with the squash word set.

A format attribute name, value, and target are the same kind of word. `SetFormatAttribute` and `StopFormatAttribute` use `GetIdentifier`. `argument` on a word element stays a `GetWord` name. `FormatAttributes` and `FormatFor` read those words from `Word` where `culture` is null.

`ContentElements` and `ContentHistory` report kind `word`, `sentence`, `paragraph`, or `dynamic`. Kind is `paragraph` only when the paragraph is set. Kind is `dynamic` when `name` and `type` are set and word, sentence, and paragraph are null. `value` is null on a dynamic row. `identifier` and `identifierType` are the culture-null words. A word element with an argument is kind `word`.

`ContentBody(content, target, culture)`, `SiteContent(site, target, culture)`, and `ListContent(list, target, culture)` take `Culture.name`. A null or unknown name uses culture 1033. A word, sentence, or paragraph uses that culture's text, or the 1033 text of the same id when that culture has no row. The element stays in the result. A dynamic element has no text. The two-argument calls use `ClientCulture()` and leave it unchanged. SQLite has the views and no culture argument. Those views read culture 1033 through the I18N views.

The Go package walks one content id, a site, or a list once. `ComposeContent`, `ComposeSite`, and `ComposeList` take a culture name and a function for dynamic text. A nil function skips dynamic rows. The identifier strings are not written into the result. A nil renderer uses the target identifier: `html` calls `HTML`, `mime` calls `MIME`, and `txt` joins the texts. `HTML` and `MIME` are exported, and a caller can pass a different renderer.

`HTML`, and the HTML part of `MIME`, read the attribute name `class` and the tokens `heading`, `lede`, and `note`. Those three match any case, and the class in the tag is lowercase. `heading` is an h2 with that class. `lede` and `note` are paragraphs with that class. Any other class token is copied as stored onto a paragraph. No class is a paragraph. Text is escaped. There is no style element. `MIME` is `multipart/alternative`: a `text/plain` part, then a `text/html` part. It sets no subject and no address. The package does not ship CSS.

`Sample/SQL/Content/notice.sql` stores one notice template: a heading sentence, a dynamic `link` of type `url`, a lede sentence, and a dynamic `count` of type `number`. fr-FR and es-MX are on the sentences only. Static content id 11 carries the same sentences. The class tokens use a null target, so `html` and `mime` both receive them. `ExampleFill` returns `https://example.test/notice` for `link`/`url` and `2` for `count`/`number`. Thank-you content id 10 stays a sentence plus a plural word.

0.2.15 is not a release. More changes are still landing on this hop. A fresh `business.sqlite3` from this tree stamps Business 0.2.15 so a develop build is distinct from the published 0.2.14 file. A file downloaded from the 0.2.14 release can still report 0.2.11. `./scripts/upgrade-sqlite.sh 0.2.14 0.2.15` treats that file as 0.2.14 when `Entitlement` and `SchemaVersions` are present, restamps 0.2.14, and applies this hop. The hop does not stamp 0.2.15 until `STAMP_VERSION=1`.

Check the active row:

```sql
SELECT build, schemaName, value
FROM SchemaVersions
WHERE stop IS NULL;
```
