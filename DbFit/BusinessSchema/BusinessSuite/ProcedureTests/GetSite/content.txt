GetSite

Site.name is a Sentence id. A second call returns the same site.

!|Query|SELECT GetSite('DbFit Site')|
|getsite?|
|>>site|

!|Query|SELECT GetSite('DbFit Site')|
|getsite|
|<<site|

!|Query|SELECT value FROM Sentence WHERE id = (SELECT name FROM Site WHERE id = _:site::INT) AND culture = 1033|
|value|
|DbFit Site|
