Anonymous session does not write IndividualSessionCreated
!|Query|SELECT COUNT(*) AS n FROM IndividualSessionCreated isc JOIN SessionCredential sc ON sc.id = isc.sessionCredential WHERE sc.credential IS NULL|
|n|
|0|

SetSession with a credential that has an individual writes IndividualSessionCreated
for that individual and the SessionCredential row just used.

!|Execute|INSERT INTO Password (value) VALUES ('dbfit-session')|

!|Query|SELECT id FROM Password WHERE value = 'dbfit-session'|
|id?|
|>>pwd|

!|Execute|INSERT INTO Credential (individual, username, password, culture) VALUES (1, 'dbfitsess', _:pwd::INT, 1033)|

!|Query|SELECT id FROM Credential WHERE username = 'dbfitsess'|
|id?|
|>>cred|

!|Query|SELECT SetSession('DbFitISCToken', NULL, NULL, _:cred::INT, NULL, NULL, NULL)|
|setsession?|
|>>sess|

!|Query|SELECT COUNT(*) AS n FROM IndividualSessionCreated WHERE individual = 1 AND sessionCredential IN (SELECT id FROM SessionCredential WHERE credential = _:cred::INT)|
|n|
|1|

Same pair is not inserted again
!|Query|SELECT SetSession('DbFitISCToken', NULL, NULL, _:cred::INT, NULL, NULL, NULL)|
|setsession|
|<<sess|

!|Query|SELECT COUNT(*) AS n FROM IndividualSessionCreated WHERE individual = 1 AND sessionCredential IN (SELECT id FROM SessionCredential WHERE credential = _:cred::INT)|
|n|
|1|

A different token is a different SessionCredential, so a new pair
!|Query|SELECT SetSession('DbFitISCTokenB', NULL, NULL, _:cred::INT, NULL, NULL, NULL)|
|setsession?|
|>>sessb|

!|Query|SELECT COUNT(*) AS n FROM IndividualSessionCreated WHERE individual = 1 AND sessionCredential IN (SELECT id FROM SessionCredential WHERE credential = _:cred::INT)|

|2|

IndividualSessions is the current individual to session report join (all sites).
Anonymous and no-individual credentials are omitted.

!|Query|SELECT individual, username, token FROM IndividualSessions WHERE username = 'dbfitsess' ORDER BY token|
|individual|username|token|
|1|dbfitsess|DbFitISCToken|
|1|dbfitsess|DbFitISCTokenB|

!|Query|SELECT COUNT(*) AS n FROM IndividualSessions WHERE username = 'dbfitnoid'|
|n|
|0|

Revoked credential drops off IndividualSessions
!|Execute|UPDATE Credential SET revoked = NOW() WHERE id = _:cred::INT|
